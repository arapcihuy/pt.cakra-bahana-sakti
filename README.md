# PT. Cakra Bahana Sakti - Company Profile Website

Official company profile website for **PT. Cakra Bahana Sakti**, a leading provider of substation accessories and industrial engineering solutions.

![Logo](public/images/logo-cbs.png)

## 🏢 About the Project

This web portal serves as the digital presence for PT. Cakra Bahana Sakti, showcasing their products, services, and corporate identity. The platform is designed to provide comprehensive information to clients and partners about the company's capabilities in the industrial engineering sector.

**Live Site:** [cakrabahanasakti.com](https://www.cakrabahanasakti.com/)

## ✨ Key Features

- **Product Catalog:** Detailed showcase of substation accessories and engineering products.
- **Corporate Information:** Vission, Mission, and Core Values visualization.
- **Multi-language Support:** Internationalization (i18n) for broader accessibility.
- **Location & Contact:** Interactive maps and contact information for various office locations.
- **Download Center:** Access to product catalogs and proposals (PDF).

## 🛠️ Technology Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **UI library:** Shadcn UI
- **Styling:** Tailwind CSS
- **Internationalization:** next-i18next
- **Icons:** Lucide React

## 🚀 Development

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev
```

## 📂 Project Structure

- `/app`: Application routes and layouts
- `/components`: Reusable UI components (shadcn/ui)
- `/public`: Static assets (images, catalogs)
- `/locales`: Translation files (en/id)
